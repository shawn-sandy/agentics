# General Issue Template

Use this body skeleton for `selection` and `session` sources — when the issue seed is a pasted text selection or a synthesized summary from the current session.

```markdown
## Summary

{{One-sentence description of the issue.}}

## Context

{{For `selection`: paste or summarize the selected text / error / code that prompted this issue.}}
{{For `session`: describe what was surfaced in the conversation — the bug found, TODO identified, or feature discussed.}}

## Details

{{Expand on the context: what specifically needs to be tracked, fixed, or built. Include any relevant snippets, error messages, or observations.}}

## Related Files

{{List file paths identified via Grep/Glob that are related to this issue.}}

## Suggested Next Action

{{What should happen next: investigation, implementation, design, documentation?}}

## Additional Context

{{Links, references, prior art, open questions.}}
```

## Suggested labels

Choose based on content: `bug`, `enhancement`, `documentation`, `chore`, `question`.
