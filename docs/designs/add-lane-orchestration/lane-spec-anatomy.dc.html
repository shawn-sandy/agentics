Disjoint ownership
Every ## Files path matches at most one lane's owns: — one file, one owner. Overlap fails --check naming the lane.
Flat global numbering
Steps 1–4 never restart per lane, so every existing [x] marker stays valid.
lead is reserved
May omit owns:, owns the shared files (CHANGELOG.md, marketplace.json), and always runs last in the main session.
after: lead is an error
Nothing may depend on lead — it would deadlock the run. --check exits 1 naming the lane. A step outside every lane errors too.
