Step 3 — Plugin manifest

Every mod file lives under hooks/ — build-dist.mjs drops any other top-level directory.

.claude-plugin/plugin.json
{
"name": "git-agent-launcher",
"description": "...",
"author", "license", "keywords",
"homepage", "repository"
}
no "version" key — it would silently override the marketplace value
hooks/hooks.json
{ "modules": ["./register.tsx"] }
Verify
claude plugin validate --strict kit/plugins/git-agent-launcher
parses the manifest, reports no version key
