plan-agent v1.7 — self-describing HTML plans

Implementation plans now auto-build their own file-tree and expose copyable paths

  • Auto-generated file-tree: file paths extracted straight from the plan's steps, no hand-maintained list
  • Each path classified new / modified / deleted / generated by the step's action verb, then grouped by directory
  • Classification precedence when a file recurs: deleted > new > generated > modified
  • Copyable plan-source block: one-click copy of the plan's filename and relative path
  • plan-file and plan-path meta tags added; backfilled across all 24 existing plans — pure CSS, no CDN
