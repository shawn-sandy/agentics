# Plan: Add Copy Button to Next Steps and Unresolved Questions

## Context

Plan HTML files generated by `plan-agent` include prompt blocks inside collapsible "Next Steps" and "Unresolved Questions" items. These `<pre>` blocks contain Claude-pasteable prompts, but users must manually select and copy the text. A one-click copy button removes that friction and makes the prompts immediately usable.

## Objective

Add a "Copy prompt" button after every `<pre>` block inside `.next-step-prompt` and `.unresolved-prompt` elements in the plan-agent HTML skeleton and instruct Claude to include it when generating plans.

## Critical Files

- `kit/plugins/plan-agent/skills/planning/reference/SKELETON.html` — template for all generated HTML plans
- `kit/plugins/plan-agent/skills/planning/SKILL.md` — skill instructions Claude follows when generating plans
- `.claude-plugin/marketplace.json` — bump version `0.6.0` → `0.7.0`
- `kit/plugins/plan-agent/CHANGELOG.md` — add changelog entry

### 4. Add `copyPrompt` JavaScript function

**File:** `SKELETON.html`  
**Before the existing IIFE** (before `(function () {` at line 852). Add as a top-level function so inline `onclick` can resolve it:

```javascript
/* ── Copy prompt button (global — required by inline onclick) ── */
function copyPrompt(btn) {
  var pre = btn.previousElementSibling;
  if (!pre || pre.tagName !== 'PRE') return;
  var text = pre.textContent;
  var orig = btn.textContent;
  function done() {
    btn.textContent = 'Copied ✓';
    btn.classList.add('copied');
    setTimeout(function () { btn.textContent = orig; btn.classList.remove('copied'); }, 2000);
  }
  function fallback() {
    var ta = document.createElement('textarea');
    ta.value = text;
    ta.style.cssText = 'position:fixed;left:-9999px;top:-9999px;opacity:0';
    document.body.appendChild(ta);
    ta.select();
    try { document.execCommand('copy'); done(); } catch (e) {}
    document.body.removeChild(ta);
  }
  if (navigator.clipboard && navigator.clipboard.writeText) {
    navigator.clipboard.writeText(text).then(done).catch(fallback);
  } else {
    fallback();
  }
}
```

- Uses `btn.previousElementSibling` — the button is always placed immediately after its `<pre>`, so no IDs needed.
- Reads `pre.textContent` (not `.value` — `<pre>` is not a form element).
- Textarea fallback handles `file://` protocol (common for locally opened plans) and older browsers.
- Must be outside the IIFE because `onclick="copyPrompt(this)"` resolves in global scope.
