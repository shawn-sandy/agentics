## How it works

The plugin design centers on one mechanic that makes artifacts durable across sessions: every skill writes the returned publish URL into the source file's frontmatter as `artifact-url:`. Without this, a second session would mint a new page rather than updating the existing one, breaking any shared links. With it, a second session reads the frontmatter, passes the URL to the `Artifact` tool's `url` parameter, and the artifact updates in place at the same link.

`diff-artifact` is the one genuinely new generator in the plugin; the others wrap or adapt existing kit outputs. It resolves diffs in three modes: current branch vs. default branch (the default), an explicit commit range, or a PR number via `gh pr diff`. The annotated HTML page uses a sticky sidebar listing changed files with add/deletion counts, anchor-linked to each file section. A cap-and-summarize policy prevents pages from exceeding the 16 MiB artifact size limit by rendering files beyond a per-file annotation budget as one-line summary rows.

Every `diff-artifact` and `session-artifact` publish is gated behind `social-media-tools:security-scrub`. This is a blocking gate, not an advisory step — if the scrub reports findings, the skill stops with no override path, because publishing to a claude.ai URL is an external-sharing action.

`session-artifact` bundles its own `export_session.py` rather than requiring `social-media-tools` to be installed first. This was an explicit design decision: the bundle trades a small duplication for zero install-order coupling. The skill uses the bundled script to extract session turns, builds a recap in reviewer-first order (Summary, Decisions, Learnings, Files touched), and publishes the `.md` directly as an artifact.

`plan-artifact` is intentionally minimal: plan HTML generated by `plan-agent` is already self-contained and CSP-compliant, so the skill is a thin wrapper that reads the frontmatter URL, passes it through, and writes it back on first publish. The skill explicitly documents that the `.md` spec is the source of truth and the HTML should never be hand-edited.

## How to use it

```text
/plugin marketplace add shawn-sandy/agentics
/plugin install artifact-tools@agentics-kit
```

Then invoke skills from within a Claude Code session:
- `/artifact-tools:diff-artifact` — publish an annotated diff of the current branch
- `/artifact-tools:session-artifact` — publish a session recap from the newest project transcript
- `/artifact-tools:plan-artifact <path/to/plan.html>` — publish or republish a plan HTML page
