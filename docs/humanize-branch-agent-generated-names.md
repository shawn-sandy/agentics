## How it works

The old rule asked for extracted keywords, which produced abbreviated names by design — keywords are dense, not descriptive. The new rule asks for a phrase a human would use as a short commit subject: an imperative verb followed by what changed, using whole dictionary words. When a phrase would exceed the budget, trailing words are dropped at word boundaries rather than truncating mid-word.

The Case B path (user-supplied descriptive phrase argument) raised its budget from 30 to 60 characters with the same word-boundary drop rule, so user phrases no longer get chopped mid-thought.

## How to use it

The improvement applies automatically for anyone with git-agent installed. Names generated by `/git-agent:branch-agent` will be more readable with no invocation change.
