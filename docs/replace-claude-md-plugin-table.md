## How it works

CLAUDE.md is loaded in full at the start of every Claude Code session. Before this change, it contained a 13-row plugin table whose rows had grown into paragraphs — the `artifact-tools` row alone was ~250 words describing internal skill mechanics. That detail lived in three places at once: CLAUDE.md, each plugin's README.md, and `.claude-plugin/marketplace.json`. With each copy drifting independently, CLAUDE.md had become the most stale and the most expensive.

The plan follows Anthropic's context-engineering guidance that CLAUDE.md should carry repository *gotchas*, not obvious facts, and that detailed reference material belongs behind progressive disclosure rather than in the always-loaded layer.

The first step was an audit: every CLAUDE.md plugin row was compared against its plugin's README.md to find any constraint or caveat documented only in CLAUDE.md and nowhere else. Those orphaned sentences were ported into the owning README before anything was removed from CLAUDE.md.

With no orphans remaining, the plugin table was rewritten to a tightly constrained `| Plugin | Type | Purpose |` schema: one row per plugin, purpose held to under 15 words. A pointer sentence was added directing readers to README.md's generated Plugin Reference Table (produced by `scripts/build-readme-table.mjs`) and to `kit/plugins/<name>/README.md` for depth.

The final `wc -w CLAUDE.md` dropped from 1,656 words to under 800, meeting the plan's stated objective. The generated README table serves as the maintained canonical catalog; CLAUDE.md's role is now navigation cue, not documentation.

To prevent future drift, `tests/plugins/test-claude-md-budget.sh` enforces three invariants: the word count stays under 800, every plugin name in `marketplace.json` appears in CLAUDE.md, and no table row exceeds 25 words. A table row padded past 25 words makes the test exit non-zero, so the constraint is self-enforcing rather than advisory.

## How to use it

Developers and AI sessions can now find plugin details in two places:
- **README.md's Plugin Reference Table** — generated by `scripts/build-readme-table.mjs`, always current with `marketplace.json`
- **`kit/plugins/<name>/README.md`** — each plugin's own documentation, averaging ~1,800 words

To verify the CLAUDE.md budget locally: `bash tests/plugins/test-claude-md-budget.sh`
