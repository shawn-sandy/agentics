## How it works

Ship a portable `verify.sh` merge gate and a `verified-change` skill that enforces test-first, mutation-checked changes, then dogfood both into the agentics repo so no change here is proposed for merge without local proof.

GitHub Actions is frequently billing-blocked on this account. A quota-blocked run fails every job in seconds with no test output, which means red CI is not evidence of a defect and green CI is not evidence of correctness — it is evidence of nothing at all. Merge readiness has to be provable on the machine. The repo already has most of a local gate and does not know it.
