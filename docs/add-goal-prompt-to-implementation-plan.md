## How it works

Every generated HTML plan already rendered two copy-paste prompts: an **implement prompt** (strict, step-by-step) and a conditional **workflow prompt** (parallel subagent orchestration). Both are wired through three coordinated surfaces: a `<meta>` tag in `<head>` for machine readability, a visible/collapsible row in the body for human use, and a placeholder in the SKILL.md Step 2 computation that the model fills from the objective and plan path.

The goal prompt follows exactly the same three-surface pattern. The SKILL.md contract was updated so Step 2 unconditionally computes `{goal-prompt}` — a phrase shaped as "Achieve this goal: … use the plan as reference, but optimize for the outcome." There is no flag or complexity heuristic; the prompt appears on every plan.

In the skeleton, `<meta name="plan-goal">` is emitted alongside `plan-implement` and `plan-workflow`. The rendered row is a purple `<details>` element (`.plan-goal`) positioned between the green implement row and the blue workflow block, preserving the visual hierarchy. The `copyGoal()` function mirrors `copyWorkflow()` — clicking the row copies the goal text to the clipboard.

The CSS rules hide `.plan-goal` when `data-status="completed"` (consistent with the workflow block's rule) and in print media (matching the implement block's print rule). This keeps completed-plan views uncluttered and printed plans free of copy-paste UI.

The smoke test asserts the meta tag, `.plan-goal` markup with `id="goal-cmd"` and `onclick="copyGoal(this)"`, the CSS hidden-when-completed rule, the DOM order (`implement → goal → workflow`), and the SKILL.md contract documenting both the `{goal-prompt}` placeholder and the `copyGoal` function.

A subsequent fix in commit `77aa33e` (2026-09-12) changed the goal prompt prefix to lead with `"Goal:"` for visual consistency with the implement and workflow rows.

## How to use it

The goal prompt appears automatically on every plan generated by `/plan-agent:implementation-plan`. No invocation change is required.

The purple "Pursue as goal" disclosure sits between the green implement row and the blue workflow row. Clicking it expands and copies the outcome-focused prompt to the clipboard — suitable for pasting into a new session or a different model to pursue the same result with more implementation latitude.
